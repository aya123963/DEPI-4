# 🏠 House Price Prediction Project

## 📌 Project Overview
This project predicts house prices using Machine Learning techniques based on the housing dataset.  
The goal is to analyze housing features and build a model that can estimate the price of a house based on these features.

## ✨ Features
📊 Data analysis and visualization  
🤖 Training a Machine Learning model  
💾 Saving the trained model for later use  
🌐 Creating an API for predictions  
🖥️ Building a simple user interface using Streamlit
